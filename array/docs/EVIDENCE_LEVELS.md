# 证据等级与来源标签 · Evidence levels and source tags

每条写进报告的结果都要带一个等级和一个来源标签。等级回答"这个解读有多靠得住"，来源回答"这个基因型是怎么来的"。

| 等级 | 含义 | 例子 |
|---|---|---|
| **A** | 直接分型，解读明确、可重复 | ALDH2 rs671；NUDT15 c.415C>T；ABCC11 耳垢；VKORC1 −1639 |
| **A(allele)** | 等位基因直接分型，但表型不可指定（其他等位基因未覆盖） | CYP2C19 *2/*3 阴性（*17 未测）；CYP2D6 *10 阴性 |
| **B** | 由多个位点、单倍型或经验证的标签推断 | APOE ε（两位点，rs7412 纯合时无相位歧义）；TAS2R38 三位点；ABO 五位点预测；Y/mtDNA 单倍群；HLA 标签 |
| **C** | 多基因或人群统计推断 | 祖源 PCA 位置；PRS 百分位；ROH；常见 GWAS 风险位点（OR 1.2–1.4） |
| **D** | 探索性关联，个人层面无预测价值 | 行为、认知、运动、长寿、睡眠、味觉/嗅觉位点 |
| **—** | 芯片未覆盖 | 写明"未测" |

| 来源标签 | 含义 |
|---|---|
| DIRECT | 芯片直接分型的 SNP |
| INDEL | 芯片直接分型的插入/缺失（I/D 编码；准确度未知，需外部确认） |
| TAG | 标签 SNP，代表另一个未直接测的变异或 HLA 型 |
| HAPLOTYPE | 由多个位点组合推断 |
| IMPUTED | 填补得到的基因型/剂量 |
| PRS | 多基因评分 |

## 与等级配套的措辞

- A：可以写"你带…""你是…型"。
- A(allele)：只写"未检出所测的 X"，加"其他版本未测，不能判断表型"。
- B：写"由 N 个位点推断""预测为…"，并给确认途径（血清学、HLA 分型、Y 全测序）。
- C：写"在参考人群中的位置/百分位"，注明参考人群及人数。
- D：写"部分研究提过，效应小，个人看不出差别"；不写能力、性格、天赋。
