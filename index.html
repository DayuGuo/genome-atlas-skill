基因组图鉴
GENOME ATLAS

Two audited pipelines · 中文 / English report · GRCh37

把一个人的基因数据变成一份经过审计的、可复现的中英双语报告。两条流水线：一条读消费级芯片导出的 基因型表，一条读原始测序数据。脚本负责数字，写结论的规则写在 SKILL.md 里，每条读数都带证据等级。 不做医学诊断，不给用药剂量。

01 · array

芯片版genotyping array

输入 WeGene / 23andMe 风格的导出文件，约 60 万个位点、15 MB。覆盖质控、父母系单倍群、祖源主成分、 性状与药物位点、ClinVar 交叉、纯合片段，以及经过误差实测的填补后多基因评分。

  • 1000G 与 HGDP 两套祖源参考
  • Beagle 填补 + 遮蔽自检
  • 子集评分误差实测，不当作结果

02 · whole genome

全基因组版WGS · FASTQ / BAM / CRAM

输入 30× 原始测序数据。除芯片版的全部内容外，还有局部祖源与留出校准、古代 DNA 投影、星号等位基因药物 基因组、HLA 分型与疾病关联、结构变异与拷贝数、重复扩增、古老人类渗入片段、相位、血液体细胞信号。

  • 可调用掩膜：缺失与参考纯合分得清
  • 局部祖源必须与留出校准一起读
  • 行为类评分标注训练人群

关于示例报告。两份示例都来自同一位东亚男性的真实数据，本人同意公开。它们只用来看格式和写法， 其中的每一条结论都属于那个样本，不要沿用。仓库里不含任何原始数据：读段、基因型表、中间文件与配置全部在 work/ 下，已被 .gitignore 排除。
