# 方法学 · Methods

本文只记录**怎么做的**。结论写在报告里。

## 0. 总览

```

   │
```

## 1. 可调用掩膜与补全基因型集

厂商交付的 VCF 通常只列变异位点。这意味着"不在 VCF 里"有两种可能：参考纯合，或没测到。
`mosdepth --quantize` 按 MAPQ 与深度把基因组切成四档，取 `DP≥8` 的区间合并成 `callable.bed`。
`03_complete_set.py` 遍历参考面板的每个双等位 SNV：有 PASS 记录就用它，没有但落在掩膜内就写参考纯合，
否则不写（= 缺失）。所有与参考人群的比较都吃这个输出。

## 2. X 与线粒体

厂商流水线常把整条 X 按单倍体调用，包括 PAR。`02_recall_x_mt.sh` 用 `bcftools mpileup/call`
配合倍性文件重新调用（PAR 二倍体、非 PAR 单倍体），并对 MT 做全深度 pileup 以便看异质性。

## 3. 祖源

PCA 建在参考人群上（`--pca allele-wts`），目标样本用 `--score` 投影，避免一个样本扰动主成分。
"最近人群"用特征值加权的欧氏距离，不做按群体标准差的标准化（后者偏向离散度大的群体）。
局部祖源用 FLARE，参考面板来自配置；**必须**同时跑留出校准：把若干参考个体移出面板后用同样方法打分，
得到"参考人群自己是多少"的基线。对照面板（与目标祖源无关的人群）拿到的比例就是噪声底。

## 4. 药物基因组的坐标转换

PharmCAT 只接受 GRCh38。直接把 GRCh37 的 VCF 转换过去会出错：有 33 个 PharmCAT 位点的参考等位基因
在两个版本之间相反，转换后会被当成变异或漏掉。做法是先在 GRCh37 上、在掩膜内把 PharmCAT 位点的
参考纯合显式写出来，再用 Picard `LiftoverVcf --RECOVER_SWAPPED_REF_ALT` 转换。
含插入缺失的位点仍有约 94 个无法双向转换，脚本会列出来。

## 5. 多基因评分

评分文件取 PGS Catalog 的 GRCh37 harmonised 版本，按坐标与等位基因匹配到参考面板。
目标样本与参考人群在**同一位点集**上打分，百分位才有意义。位点按参考人群 MAF ≥ 0.01 过滤——
不能按目标样本自身的任何指标过滤，否则会系统性偏高。

## 6. 结构变异

Delly 给出断点证据，但对拷贝数的判断不可靠。脚本对每个 ≥2 kb 的缺失/重复取 1 kb 窗口深度中位数，
除以全基因组平均（性染色体减半），据此重新判定纯合/杂合，并丢弃深度与断点方向矛盾的调用。

## 7. 古老人类片段

用已发表的 Sprime 片段作为查询集，判断目标样本是否携带片段内的古老等位基因（≥30% 的可比位点，
且 ≥10 个位点有基因型）。报告的是**片段跨度**而不是古老祖源比例，两者不能混。
基因注释时同时给出把片段位置随机打乱后的期望，用来区分"覆盖基因多"和"覆盖了哪些基因"。

## 8. 已知不可得

- **端粒长度**：部分交付流程会滤掉低复杂度重复读段。若含 ≥7 个 TTAGGG 重复的读段比例远低于 1e-4，
  说明数据不含端粒读段，此项无法估计。
- **5-HTTLPR、MAOA-uVNTR 等重复多态**：150 bp 短读长无法可靠定型。
- **临床级 HLA 与 CYP2D6 复杂重排**：短读长结果准确但不能替代临床检测。
